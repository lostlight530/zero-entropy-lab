## 重复信号

### 1. 最后一次正确观察不能自动续期到 effect 或 completion

09-01 的 authoritative relist 只能证明 relist 时点 membership

09-02 的 ordinary permission recheck 只能证明 read 时点 permission

两者都需要把 relevant state witness 继续绑定到 protected decision boundary

### 2. current permission 与 prior-effect occurrence 不能互相替代

09-03 证明 permission invalid 能阻止新 effect, 但不能解释 historical effect 是否已经发生

completion missing 同样不能把 prior effect unknown 自动降级为 miss

### 3. relevant projection 既要完整又要避免无关 over-fencing

09-02、09-04、09-05 与 09-06 都出现 whole-global revision 对无关 metadata 的额外停止

09-04 至 09-06 则连续证明 under-fencing 同样真实: 漏掉 member policy、environment 或 credential scope 都可能产生 stale unauthorized effect

### 4. verifier implementation diversity 不能证明 semantic independence

09-05 证明 producer 与 verifier 共享 incomplete projection 时可以共同 PASS

09-06 改变 omitted dependency 为 credential scope, 并把 shared-schema verifier 拆成显式条件与 set-of-pairs 两种不同实现, 两者仍同时接受 unauthorized effect

因此 09-05 至 09-06 形成跨日重复信号: common-mode failure 可以存在于共享 semantic schema, 不要求共享代码实现

该信号达到候选所需的实质差异重复条件, 但尚未达到三个独立实验的发现门槛, 不进入 NOTES

### 5. raw reconstruction 是检测路径而不是副作用撤销机制

09-05 与 09-06 的 raw verifier 都能识别 weak producer 已经写出的 unauthorized effect

它可以阻止 false assurance, 但不能撤销历史 stale effect, 因而不能替代 effect 前 protected authorization boundary
