## 重复信号

### 1. Current state 与 historical validity持续不可坍缩

09-13 至 09-17 连续显示 current approval, current key set, current revocation knowledge 与 current timestamp interpretation不能自动改写 effect-time truth.

09-18 至 09-19 又显示 current delegated permission只决定新的 effect, 不替代 prior-effect occurrence classification.

### 2. Evidence object identity与 authority role必须匹配

09-16 证明 timestamp必须覆盖正确对象.

09-19 进一步表明 delegation history虽然是合法 provenance, 但 prior actor history并不自动成为 protected resource的 current access-control authority.

因此 evidence存在和 evidence适合当前 predicate是两个不同问题.

### 3. Stronger predicate存在双向风险

09-18 的 subject-only和 actor-only发生 under-fencing.

09-19 的 full-chain-active在 modeled RFC consumer boundary发生 over-fencing.

当前 research frontier因此不是无条件增加 gate, 而是证明 dependency completeness与 dependency relevance.

### 4. Verifier independence仍有限

09-13 至 09-19 的本地 verifier主要与 producer实现分离, 但仍共享 scenario vocabulary, trace schema或 source interpretation.

没有证据支持把这一窗口升级为完整 semantic-contract independence.
