## 研究摘要

本日研究分页 selector 的跨页一致性与 continuation 过期后的混代成员拼接，区别于 11-10 receipt multiset 研究，重点是 list snapshot provenance 和过期分页恢复语义

## 研究问题

即使分页收集的成员数量满足预期，能否把两个不同 collection generation 的成员合并并错误声明动态 selector 的 current completion

## 来源依据

- [Kubernetes API Concepts](https://kubernetes.io/docs/reference/using-api/api-concepts/) — 2026-11-11 核验，分页 continue 绑定初始 list resourceVersion，失效时可能返回 410 Gone，不能将不一致的重启分页伪装为同一 snapshot
