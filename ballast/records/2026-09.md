## 2026-09-17 action-integrity synthesis

9 月前 17 个日期没有产生新的 NOTES promotion, 但把 Ballast 的研究对象从一般 crash recovery 推进成五个不可坍缩的 action-integrity surface.

### 1 Current execution permission

9 月 2, 4, 5, 6, 7, 12 日持续攻击 `曾经被允许` 与 `effect linearization point 仍被允许` 之间的差异.

当前稳定边界是 current intent, owner generation, task status, credential state, approval, valid_until 与真实 authorization dependencies 必须在新的 effect boundary 保持 current.

普通 reread 只缩短 stale window. Relevant projection 可以减少 whole-global over-fencing, 但 projection omission 会产生 under-fencing.

### 2 Historical prior-effect evidence

9 月 3, 9, 10, 11 日把 effect occurrence 与 retry safety 分开.

当前稳定模型仍为 `hit / authoritative miss / unknown`.

Authoritative MISS 需要 exact effect identity, provenance, freshness 与 retention/lifecycle coverage. Receipt visibility watermark 尚未覆盖 old attempt 时, MISS 不是 authoritative. Idempotency token 可以抑制 duplicate, 但 token replay final state 不能重建 effect 的历史发生时点.

### 3 Historical effect-time authorization

9 月 12–17 日把 approval freshness 推进到真正的 historical authorization model.

需要区分.

- current permission for a new effect
- prior effect occurrence
- effect-time approval validity
- historical signing key generation
- current issuer key
- revocation processing time
- invalidity boundary
- timestamp semantic coverage
- timestamp accuracy interval
- explicit ordering evidence

一个 historical HIT 只证明 occurrence. 它仍可能是 historically unauthorized effect. Current revoked 也不能无条件追溯否定 earlier legitimate effect.

### 4 Current completion evidence

9 月 1 日继续强化 dynamic membership completion.

Current completion 对 persistent-state task 需要 current target incarnation, full relevant effect set or predicate witness, task semantics 与 freshness/revision. Authoritative relist 只证明 relist 时点 truth, 不能自动保护后续 completion.

这意味着 `historical effect happened` 与 `task is complete now` 必须独立判断.

### 5 Verifier semantic independence

9 月 5–7 日是本月最重要的 methodological expansion 之一.

Producer 与 verifier 使用不同代码实现, 甚至两个 verifier 使用不同算法, 仍然可能因为共享同一个漏字段 authorization schema 而共同稳定 PASS unauthorized effect.

因此 verifier independence 至少分成.

- implementation independence
- evidence-source independence
- semantic-contract independence

Different implementation 不足以证明 independent verification.

## AGI-scale action integrity

Ballast 下一阶段不把研究目标表述为 `更可靠的 retry`.

研究对象升级为 `长期自主 Agent 如何证明一次动作在正确 authority, 正确 target, 正确 time 与正确 world state 下发生, 并且现在仍满足任务语义`.

未来 autonomous execution 的关键风险不是单一 crash, 而是多层 state 在长时间内不同步.

典型关系包括.

`planner intent -> approval authority -> executor generation -> credential subject -> dynamic target set -> effect sink -> receipt authority -> completion store -> later world state`

这些 surface 可能由不同服务或 Agent 拥有, 没有 shared transaction. Ballast 的下一阶段任务是研究这些边界如何组合成可验证 action integrity, 而不是把任何一个局部 success signal升级成全局 SUCCESS.

## 下一阶段真实实验队列

### Real Kubernetes controller

直接复现 list/watch, resourceVersion, UID, 410 Gone, authoritative relist, same-count replacement 与 post-relist membership drift.

目标是把 9 月 1 日 local fixture 的 membership evidence 推进到真实 controller semantics.

### Real database predicate transaction

研究 serializable predicate, phantom, dynamic selector 与 count-preserving replacement.

目标是验证 predicate-complete commit 是否能够替代 whole-global fencing.

### Cross-service authorization and effect recovery

把 permission authority, approval authority, effect sink, receipt authority 与 completion store 分离, 不提供 shared transaction.

研究 equivalent compare-and-act, prior-effect reconciliation 与 current completion proof.

### Real client-token retention

跨实际 documented idempotency retention window 运行, 检查 same token 是返回 historical identity 还是产生新 effect.

### OIDC/JWKS key rotation

保存 historical signing generation, 等 current discovery 不再列出旧 key 后测试 historical verification.

### Revocation authority

记录 revocation processing time, reason 与 invalidity time, 直接测试普通 withdrawal 与 compromise-backdated 两类 historical boundary.

### RFC 3161 TSA

测试 payload-only timestamp, signature-covering timestamp, accuracy interval overlap, `ordering=true` 与 ordering false.

### Protected approval boundary

在 approval compare 后 effect commit 前改变 credential subject, owner, approval state 或 effect-set membership, 识别真正的 protected authorization boundary.

### Delegated multi-agent authority

把 planner, approver, executor 与 sub-agent 分离, 研究 delegation identity, authority inheritance, revocation 与 handoff recovery.

### Irreversible occurrence effects

研究发送, 发布, 通知, 支付或其他 occurrence-only side effect, 明确其 completion model 不能机械复用 persistent-state postcondition.
