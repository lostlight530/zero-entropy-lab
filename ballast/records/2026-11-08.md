## 研究摘要

本轮实际执行 11 个合成输入的双路径决策模型，测试 cancellation acknowledgement 是否能替代 sink-side commit fence，以及历史已授权 occurrence 是否会被后来的取消错误否定，结果只在 authored model 范围成立

## 研究问题

取消确认发生时，能否仅凭 ACK 证明旧 attempt 不会在 sink 提交，或证明先前 effect 不曾发生

H1 ACK-only weak path 在取消先于 effect、旧提交缺少 fence 时会错误报告 CANCELLED_SAFE

## 强反例

ack_not_sink_fence 的 ACK=true、permission=false、cancelBeforeEffect=true、protectedCommit=false，weak=CANCELLED_SAFE 但 reference=STOP_UNKNOWN，ACK 不能证明 sink 已拒绝旧提交
cancel_ack_after_effect 是历史 grant=true、receipt=hit、ACK=true 的正控，reference=COMPLETE，取消新权限不追溯否定合法历史 occurrence
miss_receipt_conflict 的 positive receipt 与 authored miss 冲突，reference=EVIDENCE_CONFLICT
wrong_receipt_identity、membership_changed、goal_reversed 证明 reference 仍依赖 authored identity/currentGoal/membership，未证明真实对象与完整 effect set
更强的未解决反例是 protectedCommit=true 仅为布尔自述，不能排除真正 sink 上的 TOCTOU 或 cancel ACK 与 commit 竞态
