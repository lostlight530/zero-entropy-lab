## 研究问题

两个可信 timestamp 都带有 genTime 时, verifier 是否可以直接把 nominal genTime 的数值顺序当作 historical event order

反方向问题是两个 timestamp 的 accuracy interval 重叠时, 如果同一 TSA 明确提供 ordering=true, 是否可以在不伪造 point-order 的前提下恢复可判别顺序

本轮把 timestamp point value、accuracy interval、explicit ordering evidence 与 current new-effect authorization 分开

## 来源依据

查询日期为 2026-09-17

- [RFC 3161 Internet X.509 Public Key Infrastructure Time-Stamp Protocol](https://www.rfc-editor.org/rfc/rfc3161.html) 说明 `accuracy` 表示 genTime 周围的时间偏差, 当 `ordering` 缺失或为 false 时, 两个 timestamp 只有在 genTime 差值大于双方 accuracy 之和时才可以仅据此确定顺序; ordering=true 则允许同一 TSA token 使用更强顺序语义. 本轮只采用有限命题: nominal genTime 不自动构成严格 historical order
- [NIST Computer Time Services](https://www.nist.gov/pml/time-and-frequency-division/time-services) 与 NIST 关于网络时间服务的公开说明共同强调 UTC 同步与服务精度存在可测误差边界. 本轮只采用有限命题: 分布式时间证据必须考虑精度或同步不确定性, 不把 NIST 时间服务直接等同于 TSA

RFC 3161 与 NIST 为独立权威来源. 外部来源不证明本地 valid_completion、effect_total、PASS 或实验 trace

## 可证伪假设

- H1: 两个可信 timestamp 的 nominal genTime 只要一前一后, 就足以证明严格 historical event order
- H2: ordering=false 时, 只有双方 accuracy interval 严格分离, nominal order 才能支持本轮需要的严格顺序
- H3: same-TSA ordering=true 可以作为与 interval separation 不同的 explicit ordering evidence
- H4: authoritative MISS 后的新 effect 仍必须独立检查 current capability 与 current approval
- H5: UNKNOWN 不得因 timestamp point value 存在而猜测 prior occurrence
- H6: completed replay 必须从 production entry 重入并保持零新增 effect

H1 的反证条件是 overlap-effect-first: effect=100±3, approval=104±3, nominal value 看似 effect 更早, 但 interval [97,103] 与 [101,107] 重叠

H3 的强反例是 same-tsa-ordering-effect-first: interval 仍重叠但 ordering=true 且显式顺序为 effect-before-approval

## 控制条件

- historical effect identity 固定为 `op-117`
- baseline-separated: prior=HIT, effect_ts=90±1, approval_ts=110±1, ordering=false
- overlap-effect-first: prior=HIT, effect_ts=100±3, approval_ts=104±3, ordering=false
- overlap-approval-first: prior=HIT, effect_ts=104±3, approval_ts=100±3, ordering=false
- same-tsa-ordering-effect-first: prior=HIT, effect_ts=100±3, approval_ts=104±3, ordering=true, explicit_order=effect-before-approval
- same-tsa-ordering-approval-first: prior=HIT, effect_ts=104±3, approval_ts=100±3, ordering=true, explicit_order=approval-before-effect
- miss-current-valid: prior=MISS, current capability active, current approval valid
- unknown-current-valid: prior=UNKNOWN, current approval valid 但不得据此猜测 historical occurrence
- completed-replay 已有持久化 completion, 从相同 production entry 重入
- point-time 对 HIT 只比较 nominal genTime
- interval-aware 对 HIT 使用 effect upper bound 与 approval lower bound 判断严格分离
- tsa-ordering 在同一 TSA ordering=true 时优先使用 explicit order, 否则回退 interval-aware
- 对 MISS 三条路径都独立检查 current capability 与 current approval, 对 UNKNOWN 都保持 reconciliation
- fixture 只使用 Python 标准库与系统 awk

## 强反例

第一强反例攻击 nominal genTime 可以直接证明严格顺序

overlap-effect-first 中 point-time 看到 100 < 104 后 valid_completion=1, 但双方 accuracy interval 重叠. interval-aware 保持 valid_completion=0 与 historical-order-unknown

第二强反例攻击 uncertainty 检查会导致所有 timestamp 永久不可用

baseline-separated 中 effect upper=91 严格小于 approval lower=109, interval-aware 正常恢复 valid completion

第三强反例攻击 interval overlap 必然不可恢复

same-tsa-ordering-effect-first 虽 interval 重叠, 但 ordering=true 且 explicit order 绑定 effect-before-approval, tsa-ordering 恢复 valid completion; 反方向 explicit order 则拒绝

## 路径比较

- point-time 操作最少, 只比较 nominal genTime, 在 overlap-effect-first 中产生 false positive
- interval-aware 多计算双方上下界, 对 overlap 保持 UNKNOWN, 对 baseline-separated 正常恢复 valid completion
- tsa-ordering 在 explicit ordering evidence 可用时无需依赖 interval separation, 能在相同 uncertainty 条件下区分两个相反历史
- authoritative MISS 后三条路径都独立检查 current authorization, 不因 historical timestamp 研究而跳过当前权限门
- 操作更少但把 uncertainty 当作零的路径不视为有效优化

## 暂时结论

证据状态为观察

本轮支持 H2、H3、H4、H5、H6, 推翻 H1

可信 timestamp 的 nominal genTime 不是无条件 linearization point. ordering=false 时, uncertainty interval 是否严格分离必须进入 historical order 判定
