## 研究摘要

本轮只研究 Pub/Sub exactly-once delivery 的 ACK generation 与 regional guarantee 是否能作为下游 effect-set 的完成证明, 不重复前日 Cloud Tasks deadline 或 SQS DeleteMessage 的具体语义

受控 V8 isolate 实际运行 32 个 reset-per-scenario synthetic fixtures、三条决策路径与 96 条模型决策, 并由独立编码 primitive verifier 逐场景重建, 研究结论只限模型

## 研究问题

同一 Pub/Sub message ID 的最新 ACK ID 成功确认后, 能否推出指定 target incarnation 的 A+B 非幂等 effects 均发生、在 effect-time 获得授权、当前 completion predicate 成立

当 ACK ID 过期、subscriber region 漂移、消息被重复 publish 为新 ID、receipt 缺失或重复、authoritative MISS 与 receipt HIT 冲突、target membership 漂移时, ack-only 与 message-ID-only 路径会否假完成

## 可证伪假设

H1 ack_proxy 在 ACK 成功但 effect receipt 缺失、额外或重复时仍错误 COMPLETE

H2 message_proxy 在同 message identity 可见时错误把 delivery identity 当成 effect-set completion

H3 full_reference 仅在 ACK generation 与 region 合同、exact query HIT、无重复无额外 A+B receipt、effect-time grant、current UID/membership 与 protected completion 同时成立时 COMPLETE

H4 covered authoritative MISS 与 positive receipt 并存时输出 EVIDENCE_CONFLICT, 无 receipt 且当前 permission、protected guard 和 unsatisfied predicate 均满足时仅输出 RETRY_ALLOWED, 不输出 COMPLETE

任一非 baseline、非合法授权后撤销对照被 reference 判 COMPLETE 即推翻本轮 H3 的当前输入域实现

## 强反例

- receipt_duplicate_A: A+A 两条收据可骗过 count-only, 但 B 缺失, reference RECONCILE
- receipt_equal_count_A_C: A+C 数量等于 A+B, 仍缺 B, reference RECONCILE
- query_miss_conflict: covered synthetic MISS 与 A+B positive receipts 冲突, reference EVIDENCE_CONFLICT
- ack_stale_id 与 ack_region_drift: ACK success 字段不能独立证明当前 delivery generation 或 regional guarantee, reference 不 COMPLETE
- current_revision_drift: 合法历史 receipt 与成功 ACK 不能越过 protected completion revision mismatch
- message_republished_new_id: 同一逻辑任务另发为新 Pub/Sub message ID, 旧 receipts 不可为新 message 完成背书
- no_receipt_covered_miss_retry: 在显式满足 modeled query/permission/guard 时仅 RETRY_ALLOWED, 不能以 ACK success 判 COMPLETE
- grant_revoked_after_effect: grantUntil 仍覆盖 effectAt, 证明 current revocation 不应追溯否定历史授权

## 路径比较

ACK-only 和 message-ID-only 路径不读取 effect receipt、grant、current membership 或 completion guard, 因而更容易产生 model-relative false COMPLETE

full_reference 增加完整 effect identity、scope 与受保护当前谓词, 但模型自身可能漏掉未编码的 effect sink、grant issuer、region fencing 或跨服务 TOCTOU, 不能将其作为线上正确率基准

## 暂时结论

PARTIAL / BOUNDED_MODEL_ONLY, Pub/Sub exactly-once 是 message delivery/acknowledgment 合同, 不自动升级为 downstream exactly-once side effects、历史授权或 task completion
