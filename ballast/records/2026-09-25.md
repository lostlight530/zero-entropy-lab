## 研究摘要

This Daily attacks whether a positive asynchronous status can be treated as a context-free completion certificate. Kubernetes documents observedGeneration as the generation on which a condition was based.

## 研究问题

Can status=True prove current completion without binding the status to the current generation and concrete target incarnation?

## 来源依据

Checked 2026-09-25.

- Kubernetes condition documentation states that observedGeneration is the metadata.generation on which the condition was based and gives generation 12 versus observedGeneration 9 as an out-of-date condition.
- Kubernetes Pod documentation states that status.observedGeneration tracks the generation corresponding to reported status and that status fields can reflect different sync-loop generations.
- Kubernetes Preconditions defines UID and resourceVersion preconditions for an operation.
- Kubernetes Job API states that JobStatus conditions are latest available observations and that completionTime is not guaranteed to establish happens-before across separate operations.

These sources support field semantics only, not the local fixture or every controller.

## 可证伪假设

H1 status alone is sufficient.
H2 generation match can replace concrete incarnation.
H3 UID match can replace status-generation freshness.
H4 separating prior-effect class, current permission, UID and generation freshness rejects the modeled stale and replacement cases.
H5 positive current status does not reclassify prior HIT or UNKNOWN.

## 控制条件

Expected UID=u1 and current generation=12. Eight scenarios: baseline, stale-generation, recreated-same-condition, recreated-stale-condition, permission-revoked, condition-false, prior-HIT-stale, prior-UNKNOWN-current. Four paths: status-only, generation-bound, uid-bound, full-axis.

## 实验设计

Run 8 scenarios x 4 paths = 32 modeled decisions. Faults include observedGeneration 9 versus generation 12, UID replacement u1 to u2, revoked current permission, HIT with stale status, and UNKNOWN with fresh status. Producer output was computed three times. A second predicate recomputation rebuilt expected decisions from raw fields. No real external mutation was executed.

## 暂时结论

Status: observation. H1-H3 are falsified by the modeled counterexamples. H4-H5 are supported only inside this controlled model. Positive status is not a context-free completion certificate.
