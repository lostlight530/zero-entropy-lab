## 研究问题

Can a regional negative read prove cross-region effect absence

## 来源依据

2026-10-19 verified original vendor documentation from two independent publishers, vendor contracts are not local execution evidence

- [AWS DynamoDB global tables MREC and MRSC](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/V2globaltables_HowItWorks.html): MREC replicates asynchronously, strong regional reads may miss other-region writes, regional conditional writes check local item versions, last-writer-wins resolves same-item conflicts, MRSC is a separate consistency mode
- [AWS global table design](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/bp-global-table-design.html): replication latency has no SLA, both AWS pages share one publisher identity
- [Google Spanner reads](https://docs.cloud.google.com/spanner/docs/reads): strong reads observe commits completed before the read starts within Spanner's own contract, stale reads are distinct, this does not establish DynamoDB or external sink semantics
